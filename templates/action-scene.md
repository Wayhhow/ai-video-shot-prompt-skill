# 动作场景提示词模板

专用于打斗、追逐、战斗等动作戏。基于视频中 Mx-Shell 提到的"动作定义提示"工作流。

## 模板

```
【基础设定】
- 时间：{时段}，{特殊光线 / 天气}
- 地点：{具体地点}，{关键环境元素}
- 人物：
  - 主角：{特征、装备、武器}
  - 敌人：{数量、类型、特征}
- 参考图描述：{主角形象} + {敌人形象}
- 声音限制：仅保留{枪声 / 机械碰撞 / 拳脚 / 武器交击}，无需BGM

【氛围画质】
- 风格核心：{电影动作}、{题材}、{质感}
- 去 AI 味：超写实、极致逼真、真人实景拍摄、电影动作捕捉
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝肢体扭曲、杜绝关节反向、杜绝光影不一致、杜绝重力失真
- 视觉基调：ARRI Alexa 65 拍摄，浅景深
- 战斗节奏：{紧凑 / 高燃 / 慢节奏 / 真实搏击}
- 色彩影调：{青橙对比 / 去饱和冷调}

【战斗参数】
- 武器：{主角武器} vs {敌人武器}
- 战斗方式：{近战 / 远程 / 混合 / 衔接}
- 战斗人数：1 vs {N}
- 动作序列：
  1. {动作 A}
  2. {动作 B}
  3. {动作 C}
  4. {收尾}

【画面内容】
- 总分镜数：{N} 个
- 总时长：约 {M} 秒
- 分镜时长比重：
  - 开场入画：{X}/{N}
  - 攻击序列：{X}/{N}
  - 收尾：{X}/{N}

【分镜 1：开场入画（{X}/{N}）】
- 景别：{远景/中景}
- 构图：{三分线/对角线}
- 运镜：{手持跟拍/快速甩镜}
- 故事内容：
  [怎么做] {主角如何进入画面}
  [为什么] {建立对峙}
  [效果] {紧张感升起}

【分镜 2：第一次攻击（{X}/{N}）】
- 景别：{特写/中景}
- 构图：{对角线构图}
- 运镜：{快速推}
- 故事内容：
  [怎么做] {具体攻击动作}
  [为什么] {消灭第一个敌人}
  [效果] {高燃爆发}

【分镜 3：第二次攻击（{X}/{N}）】
- 景别：{中近景}
- 构图：{引导线}
- 运镜：{环绕}
- 故事内容：
  [怎么做] {具体攻击动作}
  [为什么] {消灭第二个敌人}
  [效果] {节奏递进}

【分镜 4：第三次攻击 / 收尾（{X}/{N}）】
- 景别：{中景/全景}
- 构图：{中心对称/对角线}
- 运镜：{拉远}
- 故事内容：
  [怎么做] {收尾动作}
  [为什么] {完成战斗}
  [效果] {英雄剪影}
```

## 完整示例：机器人 vs 3 只丧尸

```
【基础设定】
- 时间：黄昏，夕阳低角度斜射
- 地点：加州 1 号公路旁废弃加油站，锈蚀油罐、散落汽车残骸
- 人物：
  - 主角：金属质感机器人，胸前 LED 屏显愤怒表情，配备左轮手枪 + 电磁拳
  - 敌人：3 只狂暴丧尸，皮肤灰绿、破衣、肌肉外露
- 参考图描述：金属机器人左侧 3/4 视角，LED 屏显愤怒红光；丧尸张开大口迎面扑来
- 声音限制：仅保留机械碰撞声、枪声、拳肉声，无需BGM

【氛围画质】
- 风格核心：原子朋克、末日丧尸、电影动作
- 去 AI 味：超写实、极致逼真、真人实景拍摄、电影动作捕捉
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝肢体扭曲、杜绝关节反向、杜绝光影不一致、杜绝重力失真
- 视觉基调：ARRI Alexa 65 拍摄，35mm 镜头
- 战斗节奏：紧凑、全程高燃
- 色彩影调：青橙对比色调

【战斗参数】
- 武器：左轮手枪 + 电磁拳 vs 爪击、撕咬
- 战斗方式：远程射击衔接近战格斗
- 战斗人数：1 vs 3
- 动作序列：
  1. 掏左轮 → 射击 1 号丧尸
  2. 收枪 → 电磁拳打击 2 号丧尸头部
  3. 转身 → 肘击 3 号丧尸
  4. 站立 → 敌人倒地，夕阳逆光剪影

【画面内容】
- 总分镜数：5 个
- 总时长：约 10 秒
- 分镜时长比重：
  - 分镜 1：1/5
  - 分镜 2：1/5
  - 分镜 3：1/5
  - 分镜 4：1/5
  - 分镜 5：1/5

【分镜 1：开场入画（1/5）】
- 景别：中景
- 构图：对角线构图
- 运镜：手持跟拍
- 故事内容：
  [怎么做] 主角从画面左侧快速入画，目光锁定 3 名丧尸
  [为什么] 建立对峙
  [效果] 紧张感升起

【分镜 2：掏枪射击（1/5）】
- 景别：特写（手部 + 枪）
- 构图：对角线构图
- 运镜：快速推
- 故事内容：
  [怎么做] 右手抽出左轮手枪，对准 1 号丧尸，开火
  [为什么] 远程消灭第一个敌人
  [效果] 子弹时间，枪口闪光，慢动作

【分镜 3：电磁拳（1/5）】
- 景别：中近景
- 构图：引导线（手臂）
- 运镜：环绕
- 故事内容：
  [怎么做] 收枪 → 右手蓄能 → 直拳打击 2 号丧尸头部，击飞
  [为什么] 近战消灭第二个敌人
  [效果] 高燃爆发，冲击波

【分镜 4：肘击（1/5）】
- 景别：中近景
- 构图：三分线构图
- 运镜：快速甩镜
- 故事内容：
  [怎么做] 转身 → 肘击 3 号丧尸胸口
  [为什么] 消灭第三个敌人
  [效果] 节奏递进

【分镜 5：收尾（1/5）】
- 景别：全景
- 构图：中心对称构图
- 运镜：拉远
- 故事内容：
  [怎么做] 主角站立，敌人倒地
  [为什么] 完成战斗
  [效果] 夕阳逆光剪影，电影感的英雄时刻
```

## 关键要点

1. **武器写清楚**：左轮、AK、剑、长矛、拳头、电锯……
2. **动作序列写清楚**：不写"打"，写"左拳摆击头部 + 右腿横扫膝盖"
3. **敌人数量明确**：1 vs 3 还是 1 vs 10 决定分镜数量
4. **收尾必要**：每个动作戏都要有收尾，否则感觉没打完
5. **运镜交替**：避免全程同一种运镜
6. **景别交替**：避免全程同一种景别
7. **限制词加强**：动作戏一定要加「杜绝动作僵硬、肢体扭曲」

## 多轮迭代

> 视频原话：「他给我生成的第一个版本，我可能不太喜欢，然后我又会做出一些修改，让他更详细一些……然后他可能生成了一些不对的东西，然后再做出一些限制……」

- 第一版：让 AI 出整体结构和分镜
- 第二版：手动细化分镜数量、时长、具体动作
- 第三版：补首尾画面
- 第四版：加上更具体的限制词
- 直到贴合需求

## 检验清单

- [ ] 武器、敌人数量、动作序列都明确写出（避免「打」一笔带过）
- [ ] 每个分镜的比重相加 ≈ 1（或与总时长对应）
- [ ] 每个分镜的景别/构图/运镜各自齐备
- [ ] 收尾画面存在（不是结束在攻击中途）
- [ ] 运镜 / 景别有交替（避免 5 个分镜全用同一种景别 / 运镜）
- [ ] 总字数在 200-3000 中文字之间（多分镜动作戏默认放宽，跑 `validate_prompt.py` 时加 `--min-chars 200 --max-chars 3000`）
