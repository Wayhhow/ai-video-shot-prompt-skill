# 风格预设

把"风格核心 + 视觉基调 + 色彩影调 + 氛围"打包成可复用的预设。需要时可整段复制到提示词的【氛围画质】部分。

## 预设 1：原子朋克 + 末日丧尸（《丧尸清道夫》原片风格）

```
【氛围画质】
- 风格核心：原子朋克、末日废土、丧尸、复古未来主义、铆钉金属
- 去 AI 味：超写实、极致逼真、真人实景拍摄、电影动作捕捉、废墟纪实风格
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝塑料皮肤、杜绝肢体扭曲
- 视觉基调：ARRI Alexa 65 拍摄，35mm 镜头
- 氛围：温馨场景与丧尸的荒诞反差 / 末日中的孤独与希望
- 色彩影调：青橙对比色调（teal & orange）
```

适用：废土、丧尸、机甲、复古未来

## 使用方法

1. 选一个最接近题材的预设
2. 整段复制到提示词的【氛围画质】部分
3. 根据具体场景做微调：
   - 删去不适用的关键词
   - 增加特定元素（如「废墟」「竹林」）
   - 修改色彩影调

## 风格混搭

可以混搭多个预设（取各一部分），但建议总数不超过 25 个关键词：

- 原子朋克 + 电影动作 + 青橙对比 = 动作片质感
- 赛博朋克 + 黑色电影 + 监控 = 反乌托邦
- 复古胶片 + 喜剧荒诞 = 80 年代喜剧
- 武侠 + 纪录片 = 纪实武侠
- 国产爱死机 + 原子朋克 = 东方奇观
