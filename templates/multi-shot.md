# 多分镜提示词模板

用于 2-5 个分镜的场景（8-15 秒）。每个分镜可独立选择景别/构图/运镜。

## 模板

```
【基础设定】
- 时间：{时段}，{特殊光线 / 天气}
- 地点：{具体地点}，{关键环境元素}
- 人物：{主角特征}，{装备}，{情绪状态}
- 参考图描述：{1-2 句描述参考图内容}
- 声音限制：{仅在 C-Dance 类平台必填}

【氛围画质】
- 风格核心：{3-5 个关键词}
- 去 AI 味：超写实、极致逼真、真人实景拍摄
- 限制词：{3-5 个}
- 视觉基调：{模拟设备}
- 整体氛围：{贯穿全片的氛围词}
- 色彩影调：{1 句}

【画面内容】
- 总分镜数：{N} 个
- 总时长：约 {M} 秒
- 分镜时长比重：
  - 分镜 1：{X}/{N}
  - 分镜 2：{X}/{N}
  - ...

【分镜 1：{一句话概括}】
- 比重：{X}/{N}
- 景别：{...}
- 构图：{...}
- 运镜：{...}
- 故事内容：
  [怎么做] {...}
  [为什么] {...}
  [效果] {...}

【分镜 2：{一句话概括}】
- 比重：{X}/{N}
- 景别：{...}
- 构图：{...}
- 运镜：{...}
- 故事内容：
  [怎么做] {...}
  [为什么] {...}
  [效果] {...}

【分镜 3：{一句话概括}】
- 比重：{X}/{N}
- 景别：{...}
- 构图：{...}
- 运镜：{...}
- 故事内容：
  [怎么做] {...}
  [为什么] {...}
  [效果] {...}
```

## 完整示例：温馨别墅 vs 丧尸（4 分镜）

```
【基础设定】
- 时间：下午，灿烂阳光
- 地点：豪华别墅室内 + 户外泳池
- 人物：牛仔造型男主角 + 3 只丧尸
- 参考图描述：别墅复古家具、圆弧形吧台、落地窗；泳池边是复古老爷车
- 声音限制：保留泳池水声、远处丧尸低吼，无需BGM

【氛围画质】
- 风格核心：原子朋克、末日丧尸、电影动作、荒诞喜剧
- 去 AI 味：超写实、极致逼真、真人实景拍摄
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝塑料皮肤
- 视觉基调：ARRI Alexa 65 拍摄
- 整体氛围：温馨别墅场景与丧尸出现形成强烈荒诞反差
- 色彩影调：青橙对比色调

【画面内容】
- 总分镜数：4 个
- 总时长：约 8 秒
- 分镜时长比重：
  - 分镜 1：1/4
  - 分镜 2：1/4
  - 分镜 3：1/4
  - 分镜 4：1/4

【分镜 1：泳池全景】
- 比重：1/4
- 景别：远景
- 构图：三分线构图 + 引导线（泳池水道）
- 运镜：缓慢拉远
- 故事内容：
  [怎么做] 镜头从泳池边拉远，展示豪华别墅全貌，阳光、泳池、复古老爷车
  [为什么] 建立温馨场景
  [效果] 营造平静、放松的度假氛围

【分镜 2：主角出场】
- 比重：1/4
- 景别：中景
- 构图：三分线构图
- 运镜：跟拍
- 故事内容：
  [怎么做] 主角从屋内走出，牛仔造型，皮衣，左轮手枪
  [为什么] 引入主角
  [效果] 英雄登场，帅气而从容

【分镜 3：丧尸出现】
- 比重：1/4
- 景别：中景
- 构图：引导线构图（用道路引导）
- 运镜：固定
- 故事内容：
  [怎么做] 镜头突然摇向远方，几只丧尸缓缓出现
  [为什么] 反转氛围
  [效果] 紧张感骤然升起，与前 2 个分镜的温馨形成强烈反差

【分镜 4：戏剧对峙】
- 比重：1/4
- 景别：中近景
- 构图：中心对称构图
- 运镜：缓慢推
- 故事内容：
  [怎么做] 主角与丧尸对峙，目光锁定
  [为什么] 战斗即将开始
  [效果] 戏剧张力达到顶峰
```

## 提示

1. **分镜数量**：3-5 个最常用，更多会让单镜头时间过短
2. **时长比重**：用分数（如 1/4）而非绝对秒数
3. **转场**：在分镜之间说明转场方式（切换、甩镜、叠化）
4. **整体氛围**：写在【氛围画质】部分，贯穿全片
5. **局部氛围**：每个分镜的「效果」可单独写局部氛围

## 检验清单

- [ ] 总分镜数明确
- [ ] 每个分镜的比重明确
- [ ] 每个分镜的景别/构图/运镜各自齐备
- [ ] 每个分镜的故事内容用「怎么做 / 为什么 / 效果」
- [ ] 整体氛围与局部氛围的层次清晰
- [ ] 总字数在 200-3000 中文字之间（多分镜默认放宽，跑 `validate_prompt.py` 时加 `--min-chars 200 --max-chars 3000`）
