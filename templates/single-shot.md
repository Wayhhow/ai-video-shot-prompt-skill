# 单镜头提示词模板

用于单镜头一镜到底的场景（5-10 秒）。如果需要多个分镜，请用 `multi-shot.md` 或 `action-scene.md`。

## 模板

```
【基础设定】
- 时间：{时段}，{特殊光线 / 天气}
- 地点：{具体地点}，{关键环境元素}
- 人物：{主角特征}，{装备}，{情绪状态}
- 参考图描述：{1-2 句描述参考图内容}
- 声音限制：{仅在 C-Dance 类平台必填} 保留{对白/环境音}，无需BGM

【氛围画质】
- 风格核心：{3-5 个关键词}
- 去 AI 味：超写实、极致逼真、真人实景拍摄
- 限制词：{3-5 个最相关}
- 视觉基调：{模拟设备}
- 氛围：{1 句反差/对比描述}
- 色彩影调：{1 句}

【画面内容】
- 分镜：单镜头一镜到底，约 {N} 秒
- 景别：{特写/近景/中景/远景/全景/微距/大广角/监控/POV}
- 构图：{三分线/黄金分割/对角线/引导线/荷兰角/中心对称/框架式}
- 运镜：{推/拉/摇/移/跟/固定/手持/第一人称/希区柯克/环绕/低角度仰拍/航拍}
- 故事内容：
  [怎么做] {具体动作}
  [为什么] {因果链}
  [效果] {希望观众感受到的氛围/情绪}
```

## 填空示例

```
【基础设定】
- 时间：黄昏，夕阳低角度斜射
- 地点：加州 1 号公路旁废弃加油站，背景是红色岩壁
- 人物：40 岁男性清道夫，左脸烧伤疤痕，褪色皮夹克，配备自制电磁脉冲步枪
- 参考图描述：手持步枪的男性侧身特写，黄昏光，半侧脸
- 声音限制：仅保留机械碰撞声与环境音，无需BGM

【氛围画质】
- 风格核心：原子朋克、末日废土、电影动作
- 去 AI 味：超写实、极致逼真、真人实景拍摄、电影动作捕捉
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝塑料皮肤、杜绝肢体扭曲
- 视觉基调：ARRI Alexa 65 拍摄，35mm 镜头
- 氛围：宁静的黄昏与即将到来的战斗形成强烈反差
- 色彩影调：青橙对比色调，高光偏暖、阴影偏冷

【画面内容】
- 分镜：单镜头一镜到底，约 5 秒
- 景别：中景
- 构图：三分线构图，主体在画面右侧 1/3
- 运镜：手持跟拍
- 故事内容：
  [怎么做] 主角缓缓抬起电磁脉冲步枪，瞄准远方
  [为什么] 因为远方出现了几个丧尸身影
  [效果] 营造电影感的英雄时刻与紧张氛围
```

## 填空步骤

1. **基础设定**：
   - 时间 → 写「时段 + 特殊光线」
   - 地点 → 写「城市/区域 + 关键环境元素」
   - 人物 → 写「主角特征 + 装备 + 状态」
   - 参考图 → **必须先用 1-2 句描述参考图内容**
   - 声音 → **C-Dance 类平台必填，其他可省**

2. **氛围画质**：
   - 风格核心 → 选 3-5 个与题材匹配的关键词
   - 去 AI 味 → **强制** 写「超写实、极致逼真、真人实景拍摄」
   - 限制词 → 选 3-5 个最相关的反向约束
   - 视觉基调 → 选 1 个设备
   - 氛围 → 写 1 句反差/对比
   - 色彩影调 → 选 1 句

3. **画面内容**：
   - 分镜 → 写「单镜头一镜到底，约 N 秒」
   - 景别 → 选 1 个
   - 构图 → 选 1 个 + 主体位置
   - 运镜 → 选 1-2 个
   - 故事内容 → 用「怎么做 / 为什么 / 效果」三段式

## 检验清单

写完后用以下清单自检：

- [ ] 三大部分标记齐全（【基础设定】【氛围画质】【画面内容】）
- [ ] 参考图有 1-2 句描述
- [ ] C-Dance 类平台加入了声音限制
- [ ] 「超写实、极致逼真、真人实景拍摄」已加入
- [ ] 至少 3 个限制词
- [ ] 景别 / 构图 / 运镜 各选了 1 个
- [ ] 故事内容用了「怎么做 / 为什么 / 效果」三段式
- [ ] 总字数在 100-1500 中文字之间（与 `scripts/validate_prompt.py` 默认区间一致；多分镜可用 `--min-chars 200 --max-chars 3000`）

> 完整 12 条质量清单见 [references/prompt-quality-checklist.md](../references/prompt-quality-checklist.md)（v0.2 引入）。
