# 三大部分框架详解

视频中 Mx-Shell 反复强调：他的提示词**始终**由三大部分按固定顺序组成，顺序敏感。

## 1. 基础设定

> 「首先基础设定值得就是时间、地点、人物这些关键元素。」

### 1.1 时间

明确写出：

- 一天中的时段（黄昏 / 黎明 / 正午 / 深夜）
- 时代背景（现代 / 末日第 N 天 / 2077 赛博时代 / 民国）
- 特殊节庆（春节 / 圣诞 / 万圣节）

例：

- `黄昏时分，夕阳低角度斜射`
- `末日第七天，废墟中的临时营地`

### 1.2 地点

写清楚地理位置 + 关键环境元素：

- 城市/乡村/室内/室外
- 标志性建筑或地标
- 天气、能见度

例：

- `加州 1 号公路旁的废弃加油站，背景是红色岩壁`
- `上海老弄堂里的杂货铺，招牌是褪色的蓝底白字`

### 1.3 人物

按"主角特征 + 装备 + 状态"描述：

- 名字 / 代号 / 职业
- 年龄段、体型
- 标志性外观（伤疤、纹身、发型、服饰）
- 装备 / 武器
- 当前情绪 / 状态

例：

- `主角"清道夫"，40 岁男性，左脸从眉骨到下颌有烧伤疤痕，穿褪色皮夹克，配备自制电磁脉冲步枪，神情警觉`

### 1.4 参考图描述

> 「很多人会觉得只要把图片做好然后直接丢给 AI，然后把文案给他就可以了，但是这里是一个很大的误区。而我通常的习惯会把参考图给到小云雀以后，对其进行一个简单的描述。」

**强制要求**：上传参考图后必须先用 1-2 句话描述内容，让 AI 知道你给的是什么，并锁定一致性。

反面：`[上传参考图] 帮我做这个`
正面：`[上传参考图] 这是一张 40 岁男性皮夹克持枪的侧身特写，黄昏光，半侧脸。后面保持这个人物形象和构图。`

### 1.5 声音限制（仅在 Seedance 类自动配乐平台必填）

> 「Seedance 2.0 是音化同步生成，他在之前使用沉浸式短片的时候，他经常会自动为我生成一些后期制作才要用到的氛围音还有背景音乐这些，而我是需要后期剪辑和二次配乐的，为了保证这个剪辑的时候的过度的自然，我就会对声音加入一些限制。」

如果用即梦 / Vidu / 可灵 / 小云雀等会自动配BGM的平台，必须显式限制：

```
[声音限制] 无需背景音乐、无需氛围音、仅保留对白与环境音。
```

如果用 Sora / Runway 等不自动配乐的平台，可省略此段。

## 2. 氛围画质

> 「第二个氛围画质，这个其实是画面最终呈现质感的关键。」

### 2.1 风格核心

用 3-5 个关键词锚定整体风格。常见组合：

| 题材 | 关键词组合 |
| --- | --- |
| 原子朋克 | `原子朋克、复古未来主义、铆钉金属、蒸汽朋克、霓虹灯` |
| 末日丧尸 | `末日废土、丧尸、灰黄调、锈蚀、破败` |
| 电影动作 | `电影动作片、爆炸、追车、慢动作、子弹时间` |
| 喜剧幽默 | `喜剧、夸张表演、卡通化表情、荒诞` |
| 武侠 | `水墨、烟雨、竹林、剑光、留白` |
| 赛博朋克 | `赛博朋克、霓虹、雨夜、义体、机械` |

### 2.2 限制词

明确写出**不要**什么，反向约束更有效：

- `杜绝游戏CG感`
- `杜绝动作僵硬`
- `杜绝镜头漂移`
- `杜绝塑料皮肤`
- `杜绝人物畸形手指`
- `杜绝过度曝光`

### 2.3 视觉基调（设备模拟）

> 「视觉基调是用来让 AI 模拟一些拍摄的设备以达到真实拍摄的效果。」

让 AI 模拟特定设备/胶片：

- 数字电影机：`ARRI Alexa 65`、`RED V-Raptor`、`Sony Venice`
- 经典数字：`Canon EOS R5`、`Sony A7S III`、`Blackmagic URSA`
- 胶片：`Kodak Vision3 500T`、`Fuji Eterna Vivid 500`
- 特殊：`iPhone 15 Pro 竖屏`、`GoPro Hero 12 广角`、`监控摄像头 4:3 标清`、`无人机 DJI Mavic 3 航拍`

例：`采用 ARRI Alexa 65 拍摄，浅景深，35mm 镜头`

### 2.4 氛围描述

写 1-2 句**反差/对比**让画面张力更足：

- 「温馨的下午茶场景与突然闯入的丧尸形成强烈的荒诞反差」
- 「宁静的竹林与刀剑相击的清脆金属声形成动静对比」
- 「暴雨中的霓虹街道反射在湿漉漉的柏油路上」

### 2.5 色彩影调

> 「大家可以学习一下后期的调色相关的专业知识，或者是多看看电影，多分析一下。」

1 句话锁定色彩：

- `青橙对比色调，高光偏暖，阴影偏冷`
- `去饱和冷调，模拟朝鲜战争纪录片风格`
- `黑白高反差，模拟黑色电影 noir`
- `暖黄高光 + 深青阴影，赛博朋克霓虹`

## 3. 画面内容

> 「第三个部分就是画面内容，顾名思义就是你的视频想要表达什么也是关键的重点。」

### 3.1 分镜

明确写出：

- **单镜头** vs **多分镜**
- 如果多分镜：每个分镜的侧重与**时间占比**（不是绝对时长，是相对比重）
- 时间占比示例：
  - `单镜头一镜到底，约 5 秒`
  - `多分镜：前 2/3 为主角入画与对峙，最后 1/3 为快速击杀与收尾`

### 3.2 景别

视频中提到的清单：

- `特写`（眼、嘴、武器细节）
- `近景`（胸部以上）
- `中景`（膝盖以上）
- `远景`（全身）
- `全景`（人物 + 环境）
- `微距`（极近距离细节）
- `大广角`（夸张透视）
- `监控镜头`（4:3 标清 / 鱼眼 / 顶部俯瞰）
- `第一人称 POV`

### 3.3 构图

- `三分线构图`（主体放在 1/3 交点）
- `黄金分割构图`（与三分线近似但更精确）
- `对角线构图`（动感）
- `引导线构图`（用线条引导视线）
- `荷兰角`（倾斜，紧张感）
- `中心对称构图`（庄重、仪式感）
- `框架式构图`（用门、窗框住主体）

并写出主体在画面中的位置 + 前景 / 背景。

### 3.4 运镜

- 基础：`推 / 拉 / 摇 / 移 / 跟 / 固定`
- 特殊：
  - `手持拍摄`（新闻感、临场感）
  - `模拟第一人称`（沉浸）
  - `希区柯克变焦`（背景压缩 + 主体不变，心理惊悚）
  - `环绕运镜`（360 度）
  - `低角度仰拍`（高大、英雄）
  - `高角度俯拍`（渺小、被压迫）
  - `航拍 / 无人机`（大全景）
  - `一镜到底`（无剪辑，长镜头）

### 3.5 故事内容

> 「想到什么就写什么，跟说白话和别人聊天一样。唯一的技巧也是我认为的重点，就是大家可以考虑加入一些氛围的提示词。」

用「**要怎么做 → 为什么要这样做 → 想要什么效果**」三段式描述：

- 怎么做：动作的具体执行方式
- 为什么：因果链，让 AI 理解意图
- 效果：希望观众感受到的氛围/情绪

**视频中的鸵鸟示例**：

```
鸵鸟脚掌猛踩报纸（怎么做），
然后被粘到脚上带走（效果），
另一只脚抬起试图甩开粘在脚上的报纸（怎么做），
因为脚上粘住了报纸使其很不舒服（为什么），
于是改变奔跑模式变为单脚跳跃前进（效果），
整体氛围幽默诙谐、荒诞滑稽（氛围）。
```

**动作戏示例**：

```
主角进入画面（怎么做），
用左轮手枪衔接肢体进行近战攻击（怎么做），
依次解决 3 名丧尸敌人（怎么做），
采用快节奏镜头切换（运镜），
最后做出收尾动作（怎么做），
整体氛围紧凑高燃（氛围）。
```

## 三大部分的顺序

**基础设定 → 氛围画质 → 画面内容** 固定。

理由：
- 基础设定先定锚（人/地/时）
- 氛围画质定调（看起来是什么感觉）
- 画面内容最后讲故事（具体发生什么）

AI 对前文权重更高，所以"风格"和"限制词"放中段而非开头，能避免污染基础设定的字面理解。
