# 景别 / 构图 / 运镜 完整清单

视频中 Mx-Shell 提到："大家其实都是可以去了解一下，包括我要讲的第三点"——他反复强调景别、构图、运镜是**摄影和影视相关的基础知识**，对写好提示词非常重要。

## 景别 (Shot Size)

| 景别 | 描述 | 适用 |
| --- | --- | --- |
| **极特写 ECU** | 仅眼睛、嘴唇、指纹等极小局部 | 情绪高潮、细节揭示 |
| **特写 CU** | 面部填满画面 | 表情、对话、反应 |
| **中特写 MCU** | 头部 + 肩部 | 台词、情感交流 |
| **近景 MS** | 胸部以上 | 对话、过肩镜头 |
| **中景 MLS** | 膝盖以上 | 多人对话、动作起始 |
| **全景 LS** | 全身 | 人物动作、走位 |
| **远景 ELS** | 人物小、强调环境 | 史诗、环境叙事 |
| **大远景** | 几乎看不到人物 | 大场面、空镜 |
| **微距** | 极近距离，小物体 | 昆虫、液体、细节质感 |
| **大广角** | 强烈透视变形，夸张前后景 | 喜剧、动作、恐怖 |
| **鱼眼** | 圆形畸变 | 监控感、运动镜头 |
| **监控/POV** | 第一人称/监控视角 | 沉浸、窥视、恐怖 |

## 构图 (Composition)

### 经典构图

- **三分线构图 (Rule of Thirds)**
  - 主体放在画面 1/3 或 2/3 处的交点
  - 通用、稳定
  - 适合大部分场景

- **黄金分割 (Golden Ratio / 斐波那契)**
  - 与三分线近似但更精确
  - 经典艺术构图

- **中心对称 (Center Symmetry)**
  - 主体居中
  - 庄严、仪式感、肖像

- **对角线构图 (Diagonal)**
  - 主体沿对角线分布
  - 动感、冲突

- **引导线构图 (Leading Lines)**
  - 用道路、栏杆、墙缝等线条引导视线到主体
  - 强化空间感

- **S 型构图 (S Curve)**
  - 河流、街道、人物动作呈 S 形
  - 优雅、流动

- **三角形构图 (Triangle)**
  - 三个主体形成三角形
  - 稳定、群像

- **荷兰角 (Dutch Angle)**
  - 画面倾斜 15-30°
  - 紧张、不安、心理失衡
  - 恐怖/惊悚常用

### 进阶构图

- **框架式构图 (Frame within Frame)**
  - 用门、窗、树枝、栏杆"框住"主体
  - 隔离、聚焦

- **前景遮挡 (Foreground Obstruction)**
  - 前景有元素（手、武器、墙）部分遮挡
  - 临场感、窥视感

- **负空间构图 (Negative Space)**
  - 大量留白，主体小
  - 孤独、渺小、禅意

- **呼应构图 (Call and Response)**
  - 前景一个元素，后景一个元素呼应
  - 叙事、对比

## 运镜 (Camera Movement)

### 基础运镜

| 运镜 | 英文 | 描述 |
| --- | --- | --- |
| **推** | Dolly in / Push in | 镜头向前推进，主体变大 |
| **拉** | Dolly out / Pull back | 镜头向后拉远，揭示环境 |
| **摇** | Pan | 镜头水平旋转（固定机位） |
| **移** | Tracking / Truck | 镜头水平平移（移动机位） |
| **跟** | Follow | 镜头跟随主体运动 |
| **固定** | Static | 镜头不动 |

### 高级运镜

- **手持 (Handheld)**
  - 微抖、临场感
  - 新闻片、战斗、恐怖

- **斯坦尼康 (Steadicam)**
  - 平稳但有运动感
  - 长镜头跟随

- **环绕 (Orbit / Arc)**
  - 围绕主体旋转 90-360°
  - 展示、慢动作

- **升降 (Crane / Boom / Pedestal)**
  - 上下运动
  - 揭示、仪式感

- **航拍 (Aerial / Drone)**
  - 高空俯瞰
  - 大场面、城市、风景

- **推轨变焦 (Dolly Zoom / Vertigo / 希区柯克变焦)**
  - 镜头推进同时变焦拉远（或反之）
  - 背景压缩/拉伸，主体不变
  - 心理惊悚、空间扭曲

- **一镜到底 (One Shot)**
  - 无剪辑连续镜头
  - 复杂调度、炫技

- **甩镜 (Whip Pan)**
  - 快速横摇，制造模糊
  - 转场、紧张、漫画感

- **低角度仰拍 (Low Angle)**
  - 镜头低于主体，向上拍
  - 力量、英雄、压迫

- **高角度俯拍 (High Angle)**
  - 镜头高于主体，向下拍
  - 渺小、被控制

- **荷兰角 (Dutch Angle)**
  - 画面倾斜
  - 不安、心理失衡

- **第一人称模拟 (POV)**
  - 镜头即角色眼睛
  - 恐怖游戏、动作

- **肩扛跟拍 (Over-the-Shoulder Follow)**
  - 镜头从主体肩后跟随
  - 动作片常用

- **垂直俯冲 (Top-Down)**
  - 完全正上方俯瞰
  - 监控、舞蹈、动作编排

## 运镜 + 景别 + 情绪 速查

| 情绪 | 推荐组合 |
| --- | --- |
| 紧张对话 | 中近景 + 三分线 + 微推 |
| 史诗开场 | 大远景 + 航拍 + 慢推 |
| 恐怖揭示 | 极特写 + 摇 + 荷兰角 |
| 动作追击 | 中景 + 手持 + 跟拍 + 快速甩镜转场 |
| 浪漫时刻 | 中近景 + 中心对称 + 慢推 |
| 喜剧夸张 | 中景 + 大广角 + 低角度 + 急推 |
| 心理惊悚 | 中景 + 推轨变焦（希区柯克）|
| 战争全景 | 远景 + 航拍 + 摇 + 跟 |
| 内心独白 | 特写 + 固定 + 浅景深 |
| 动作高潮 | 全景 + 慢动作 + 环绕 |

## 实战建议

1. **新手优先用「中景 + 三分线 + 跟拍」万能组合**
2. **动作戏推荐「中景 + 手持 + 推拉交替」**
3. **场景开头用「远景 + 拉/航拍」交代环境**
4. **关键道具用「特写 + 推」强调**
5. **情绪高潮用「慢动作 + 环绕 + 推」渲染**
6. **恐怖/惊悚用「荷兰角 + 摇 + 极特写」**
7. **不要在同一个镜头里堆砌太多运镜**——选 1-2 个即可
