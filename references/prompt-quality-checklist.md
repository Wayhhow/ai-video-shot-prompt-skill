# AI 视频提示词质量清单（v0.2 引入）

把 SKILL.md 的"反模式"沉淀为 12 条可勾选清单。写完提示词后逐条勾选，**至少 11/12 通过**才视为可发布。

> 配对使用：跑 `python scripts/validate_prompt.py your-prompt.md` 看机器检查结果，再用本清单做人工审视。

## 快速勾选（12 条）

- [ ] **1. 三大段齐全（用【】包裹）**
- [ ] **2. 三大段顺序正确**（基础设定 → 氛围画质 → 画面内容）
- [ ] **3. 参考图描述存在**（参考图描述：xxx，至少 4 个中文字）
- [ ] **4. 声音限制明确**（【基础设定】含"声音限制"或"BGM"或"配乐"）
- [ ] **5. 去 AI 味关键词 ≥ 1**（超写实 / 极致逼真 / 真人实景拍摄 至少 1）
- [ ] **6. 限制词 ≥ 3**（"杜绝 xxx" 至少 3 个）
- [ ] **7. 景别 / 构图 / 运镜 各自 1 个**（每个分镜同时含三项）
- [ ] **8. 故事内容用"怎么做/为什么/效果"三段式**
- [ ] **9. 故事内容有"为什么"**（这是分镜质量的关键）
- [ ] **10. 武戏/动作戏不使用"打"一笔带过**（明确武器、敌人数量、动作序列）
- [ ] **11. 不含命令式反模式**（不用"必须""一定要""完美的"等）
- [ ] **12. 总字数在合理区间**（单镜头 100-1500；多分镜 200-3000）

## 详细说明

## 1. 三大段齐全（用【】包裹）

- **怎么判**：文件里同时出现 `【基础设定】`、`【氛围画质】`、`【画面内容】` 三个标题。
- ❌ 反例：`基础设定：xxx`（无【】包裹，旧风格，v0.2 起会被校验脚本判为缺失）
- ✅ 正例：`【基础设定】\n- 时间：黄昏\n- 地点：废弃加油站`

## 2. 三大段顺序正确

- **怎么判**：基础设定 → 氛围画质 → 画面内容 顺序出现。
- ❌ 反例：先写画面内容再补基础设定
- ✅ 正例：按本文件顺序展开
- **机器验证**：用 `python scripts/validate_prompt.py prompt.md --strict` 应退出 0

## 3. 参考图描述存在

- **怎么判**：出现「参考图描述：xxx」「参考图：xxx」或「参考图」+ 换行 + 描述；描述至少有 4 个中文字。
- ❌ 反例：`我已经上传参考图。`（仅"参考图"三字，无描述）
- ✅ 正例：`参考图描述：金属机器人 3/4 侧视角，胸前 LED 红光`

## 4. 声音限制明确

- **怎么判**：在【基础设定】里出现「声音限制」「BGM」「配乐」任一关键词。
- ❌ 反例：完全不提声音
- ✅ 正例：`- 声音限制：仅保留机械碰撞声，无需BGM`

## 5. 去 AI 味关键词 ≥ 1

- **怎么判**：包含 `超写实`、`极致逼真`、`真人实景拍摄` 至少 1 个；动作戏另加 `电影动作捕捉`。
- ❌ 反例：仅写"高质量画面"
- ✅ 正例：`- 去 AI 味：超写实、极致逼真、真人实景拍摄、电影动作捕捉`

## 6. 限制词 ≥ 3

- **怎么判**：从「杜绝 xxx」列表中至少选 3 个。
- ❌ 反例：`- 限制词：杜绝游戏CG感`（仅 1 个）
- ✅ 正例：`- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝塑料皮肤、杜绝穿模`

## 7. 景别 / 构图 / 运镜 各自 1 个

- **怎么判**：【画面内容】中每个分镜都同时含景别、构图、运镜。
- ❌ 反例：`分镜 1：- 景别：中景`（缺构图、运镜）
- ✅ 正例：
  ```
  - 景别：中景
  - 构图：三分线
  - 运镜：手持跟拍
  ```

## 8. 故事内容用"怎么做/为什么/效果"三段式

- **怎么判**：每个分镜的"故事内容"中含 `[怎么做]`、`[为什么]`、`[效果]` 三段。
- ❌ 反例：`- 故事内容：主角入画`（仅 1 段）
- ✅ 正例：
  ```
  - 故事内容：
    [怎么做] 主角从画面左侧快速入画，目光锁定 3 名丧尸
    [为什么] 建立对峙
    [效果] 紧张感升起
  ```

## 9. 故事内容有"为什么"

- **怎么判**：故事内容中出现 `[为什么]` 段。这是分镜质量的关键。
- ❌ 反例：跳过为什么直接写动作
- ✅ 正例：明确写"建立对峙"或"展示世界观"

## 10. 武戏/动作戏不使用"打"一笔带过

- **怎么判**：动作分镜明确写武器、敌人数量、动作序列。
- ❌ 反例：`分镜 1：主角打丧尸`
- ✅ 正例：`分镜 1：主角用右拳直击最近的丧尸下颚，丧尸头部侧仰，鲜血飞溅`

## 11. 不含命令式反模式

- **怎么判**：提示词不含"必须""一定要""禁止不要"等命令式语言；不含"完美""最好的"等夸大副词。
- ❌ 反例：`请生成一个完美的、史无前例的 8K 高清画面`
- ✅ 正例：直接用"风格核心"和"限制词"组合

## 12. 总字数在合理区间

- **怎么判**：单镜头 100-1500 中文字；多分镜 200-3000 中文字。
- **机器验证**：
  ```
  # 单镜头
  python scripts/validate_prompt.py prompt.md
  # 多分镜
  python scripts/validate_prompt.py prompt.md --min-chars 200 --max-chars 3000
  ```

## 进阶：跨模型适配

不同 AI 视频模型对提示词风格有偏好（参考 [references/workflow-and-storyboard.md](workflow-and-storyboard.md)）：

| 模型 | 偏好 |
| --- | --- |
| 即梦 / Vidu / 可灵 | 中文自然语言，关键词穿插；多镜头用「分镜 1：xxx，分镜 2：xxx」 |
| Sora / Runway | 英文更稳；本 skill 的中文关键词在英文模型下需翻译 |
| 小云雀 | 接受中英混合；可在每条关键词后用括号加英文 |
| Veo 3.1 | 偏好结构化描述，可在分镜前加 "Shot 1:" 等英文标签 |

## 与自检脚本的关系

- **自动检查**：`scripts/validate_prompt.py` 覆盖 1-5、7、8、12（结构层面）
- **人工检查**：6、9、10、11 需要人眼/经验判断（写作质量层面）
- **跨模型**：进阶章节不在脚本范围内，需用户自己评估
