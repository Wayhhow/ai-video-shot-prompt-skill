## 示例 1：鸵鸟粘报纸（幽默场景）

> 视频原话：「还是拿刚才这样的举例……鸵鸟脚掌猛踩报纸……」
> 时间：约 06:30-07:15

### 提示词

```
【基础设定】
- 时间：下午，灿烂阳光
- 地点：城市街道
- 人物：一只非洲鸵鸟，正在奔跑
- 参考图描述：这是一只长腿鸵鸟在城市道路上快速奔跑的瞬间
- 声音限制：保留环境音（风声、报纸沙沙声）

【氛围画质】
- 风格核心：荒诞喜剧、动物拟人化、复古胶片
- 去 AI 味：超写实、极致逼真、真人实景拍摄
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝塑料皮肤
- 视觉基调：ARRI Alexa 65 拍摄，浅景深
- 氛围：温馨的下午街景与鸵鸟的滑稽奔跑形成强烈反差
- 色彩影调：暖黄高光，模拟复古胶片质感

【画面内容】
- 分镜：单镜头一镜到底，约 5 秒
- 景别：中景 → 特写（脚掌特写）
- 构图：三分线构图，主体在画面中央偏右
- 运镜：手持跟拍 + 低角度
- 故事内容：
  [怎么做] 鸵鸟脚掌猛踩地面上一张摊开的报纸，
  [为什么] 因为报纸铺在地上是它奔跑路径的一部分，
  [效果] 然后脚掌被报纸粘住，整个报纸被拖着跑。
  [怎么做] 另一只脚抬起试图甩开粘在脚上的报纸，
  [为什么] 因为脚上粘住了报纸使其很不舒服，
  [效果] 于是改变奔跑模式，变为单脚跳跃前进，姿态滑稽。
  [氛围] 整体氛围幽默诙谐、荒诞滑稽。
```

## 示例 2：机器人踢飞丧尸（动作场景）

> 视频原话：「正好说打斗的这个……用 cx2.0 生成的动作定义提示」
> 时间：约 15:00-19:00

### 提示词

```
【基础设定】
- 时间：黄昏，夕阳低角度斜射
- 地点：加州 1 号公路旁的废弃加油站
- 人物：机器人主角（重装机甲风格），3 名狂暴丧尸敌人
- 参考图描述：金属质感机器人主角，胸前 LED 屏显愤怒表情；丧尸皮肤灰绿、破衣
- 声音限制：仅保留机械碰撞声、枪声、环境风声，无需BGM

【氛围画质】
- 风格核心：原子朋克、末日丧尸、电影动作
- 去 AI 味：超写实、极致逼真、真人实景拍摄、电影动作捕捉
- 限制词：杜绝游戏CG感、杜绝动作僵硬、杜绝肢体扭曲、杜绝光影不一致
- 视觉基调：ARRI Alexa 65 拍摄，35mm 镜头，浅景深
- 氛围：废弃的加油站、夕阳的暖光与战斗的金属碰撞形成反差
- 色彩影调：青橙对比色调，高光偏暖、阴影偏冷

【画面内容】
- 分镜：多分镜，约 10 秒
  - 分镜 1：开场入画（前 1/5）
  - 分镜 2：掏枪（1/5）
  - 分镜 3：射击（1/5）
  - 分镜 4：近战（1/5）
  - 分镜 5：收尾（1/5）
- 景别：
  - 分镜 1：中景
  - 分镜 2：特写（手部）
  - 分镜 3：中景
  - 分镜 4：中近景
  - 分镜 5：全景
- 构图：三分线构图 + 对角线构图
- 运镜：手持跟拍 + 快速甩镜转场 + 子弹时间
- 故事内容：
  [分镜 1] 主角从画面左侧快速入画，目光锁定 3 名丧尸
  [分镜 2] 主角右手抽出左轮手枪，枪口指向敌人
  [分镜 3] 主角开枪，子弹击中第一名丧尸
  [分镜 4] 主角收枪，与剩余两名丧尸近战，
            用左拳摆击头部 + 右腿横扫膝盖
  [分镜 5] 主角站立，敌人倒地，夕阳逆光剪影
  [氛围] 紧凑、全程高燃、电影动作质感
```

## 反例：什么是不好的提示词

### 反例 1：缺乏结构
```
"做一个末日丧尸清道夫，很酷的那种，电影感，要有打斗"
```
问题：
- 没有基础设定（时间地点人物）
- 没有具体动作
- 没有景别/构图/运镜
- "很酷"无法量化

### 反例 2：直接命令 AI
```
"给我做：角色在跑、跳、踢、射击，注意要动作流畅"
```
问题：
- 命令式语气
- 没有"为什么"
- 没有氛围
- 没有时间结构

### 反例 3：不分镜不写时长
```
"一个机器人打三个丧尸，要精彩"
```
问题：
- 没有分镜划分
- 没有时长或分镜比重
- 没有景别/运镜
- "精彩"模糊

## 优化路径

拿到 AI 给的初版提示词后，手动优化清单：
- [ ] 补充分镜数量（与实际需要的分镜数对齐）
- [ ] 重新分配时长比重
- [ ] 补充首尾画面（AI 经常漏）
- [ ] 把"打"改成具体动作序列
- [ ] 加入"为什么"因果链
- [ ] 加入氛围词
- [ ] 检查景别/构图/运镜是否齐备
- [ ] 加入限制词
