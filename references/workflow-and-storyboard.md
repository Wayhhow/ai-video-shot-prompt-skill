# 小云雀短剧 Agent 2.0 工作流

视频中 Mx-Shell 用小云雀（XiaoYunQue）演示了一套完整的多分镜 AI 短片工作流。整理如下。

## 1. 进入方式

```
短剧 Agent 2.0 → 自由画布（或上传剧本后跳过）
```

## 2. 准备阶段

### 选项 A：有剧本
- 上传剧本（粘贴文字即可）
- 选风格（可后改）
- 选横屏/竖屏
- 选集数

### 选项 B：无剧本
- 直接选「自由画布」
- 在画布上自由搭建

## 3. 资产拆解

点击 `剧本资产拆解 → 确定`，系统自动生成：
- 人物（主角、配角、敌人）
- 道具（武器、物品）
- 场景（地点、环境）

如缺失可手动上传或在画布里添加。

## 4. 画布编辑（核心）

### 4.1 元素类型
- 图片（角色图、场景图、道具图）
- 视频（生成的镜头）
- 音频（对白、音效）
- 节点（连接关系）

### 4.2 关键操作
- **拖动节点**：自由布局
- **加号（+）**：添加节点（图片/视频/音频/场景角色）
- **右键上传**：从本地上传素材
- **整理画布**：一键规整布局
- **重置画布**：恢复初始状态
- **网格吸附**：拖动时显示参考线
- **画布小地图**：快速定位

### 4.3 资产库
画布上已生成的素材自动归入资产库，可直接拖出复用。

## 5. 角色图生成

选中节点后可选：

- **一次性全部生成**：批量出图
- **三视图**：正面 / 侧面 / 背面三个角度
- **光影控制**：光源角度、强度、色温、软硬
  - `蝴蝶光`、`伦勃朗光`、`电影感布光`
- **镜头控制**：角度（左右/上下）、景别（特写/远景）
- **提示词**：描述姿势、表情

## 6. 视频生成（关键节点）

### 6.1 连接关系
画布上**用线连接**节点定义依赖：
```
角色图 → 视频节点
场景图 → 视频节点
表情图 → 视频节点（保持表情）
```

### 6.2 模型选择
- `cx2.0`（即 C-Dance 2.0）：默认，质量高
- `fast`：速度更快，质量略低

### 6.3 关键参数
- `分辨率`：1080p / 720p
- `画幅`：16:9 / 9:16 / 1:1
- `时长`：5s / 10s / 15s（不是绝对精准）

### 6.4 表情锁定
如需保持特定表情，用线连接「表情图节点」到视频节点。

## 7. 抽卡策略

> 「我的这个方法可能就是抽卡会比较严重……我之前抽的卡片……大概抽了 200 多个，快 300 个了……我好像还删过 20、30 来个，就是实在是看不下去的那种，就抽卡其实蛮严重的。」

**接受抽卡是常态**：
- 一次生成 2-4 个候选视频
- 实际可用的可能只有 1-2 个
- 一个 10 秒成片可能要抽 20-30 次
- 总素材 vs 成片比：约 5-10:1

**抽卡技巧**：
- 一次生成多个（默认 4 个）
- 等待几分钟出结果
- 逐个检查，不对就重新生成
- 重点关注：动作、光效、人物一致性
- 不要在第一次失败就放弃，第三次通常会有惊喜

## 8. 多分镜实操（视频中的打斗示例）

> 「这个就有好几个分镜，我之前直播说过我写文系可以用，但是写武戏我不太行……我会把我的要求还是会告诉他，用 cx2.0 生成的动作定义提示。」

### 8.1 给 AI 写「动作定义提示」

告诉 AI 的结构（视频中提到的）：

```
【内容】
- 主角怎么进入画面
- 用什么武器
- 敌人有几名
- 攻击方式（例：左轮手枪衔接肢体近战）
- 依次解决的顺序
- 收尾动作
- 战斗节奏（紧凑、全程高燃）
- 参考素材（可选）
```

### 8.2 多轮迭代

> 「他给我生成的第一个版本，我可能不太喜欢，然后我又会做出一些修改，让他更详细一些……然后他可能生成了一些不对的东西，然后再做出一些限制……」

**迭代流程**：
1. AI 生成第一版（结构/分镜/动作序列）
2. 人工细化：补充细节、调整分镜数量、修正时长
3. 加上限制：删除不要的元素（慢动作、丧尸种类等）
4. 再生成
5. 直到贴合需求

### 8.3 拿到 AI 提示词后的手动优化

> 「他给你以后就是，你不能保证你给 AI 的对话，你告诉他的东西，AI 就完全能够理解你想要什么东西，相反，AI 反馈给你的东西，你也不能够保证……所以说，你拿到 AI 给你的提示词以后，还是需要做一些简单的细化或者是优化。」

**必做的人工调整**：
- **分镜数量对齐**：AI 给 7 个分镜，但实际需要 8 个 → 手动加一个
- **时长再分配**：重新平衡各分镜的时长
- **首尾画面**：开头/结尾的画面 AI 经常漏写，需要补
- **具体动作**：把"打"改成"左拳摆击头部 → 右腿横扫膝盖"

## 9. 工作流总结

```
[准备剧本] → [资产拆解] → [画布搭建] → [生成角色图] → [写提示词] → [连接节点] → [生成视频] → [抽卡] → [筛选] → [后期剪辑]
```

每一步都可能需要多轮迭代。

## 10. 多分镜提示词结构

视频中的多分镜提示词框架：

```
【整体氛围】
- 紧凑
- 全程高燃
- 电影动作质感
- 超写实、真人实景拍摄
- 杜绝游戏CG感、杜绝动作僵硬

【分镜 1：开场入画】
- 主角从画面左侧快速入画
- 中景
- 手持跟拍
- 时间：前 1/5

【分镜 2：掏枪】
- 主角右手抽出左轮手枪
- 特写
- 快速推
- 时间：1/5

【分镜 3：射击】
- 左轮手枪开火
- 中景
- 子弹时间（慢动作）
- 时间：1/5

【分镜 4：近战】
- 主角衔接肢体近战
- 中近景
- 快速甩镜
- 时间：1/5

【分镜 5：收尾】
- 主角收枪、转身
- 全景
- 拉远
- 时间：1/5
```

> **关键**：分镜的时长用**相对比重**（1/5、1/3）而非绝对秒数，AI 不会精准卡时长。
